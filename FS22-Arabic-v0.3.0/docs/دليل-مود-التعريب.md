# مود التعريب FS22_ArabicLanguage

## التجربة

1. شغّل اللعبة، وفعّل المود «Arabic Language» عند اختيار الحفظ، ثم ادخل اللعبة.
2. يظهر أعلى الشاشة لعشرين ثانية: «مود التعريب يعمل — 50 نصاً مترجماً».
3. افتح المتجر: أسماء الألوان وأنواع الآلات وبعض الخيارات تظهر بالعربية.
4. بعد الدخول يكتب المود كل نصوص اللعبة في:
   `Documents\My Games\FarmingSimulator2022\modSettings\FS22_ArabicLanguage\l10n_source.xml`
   هذه هي القائمة الكاملة التي سنترجمها.

## الترجمة

- ضع ملف ترجمتك في `modSettings\FS22_ArabicLanguage\l10n_ar.xml` بنفس صيغة
  `translations\l10n_ar.xml`، فيقرؤه المود دون إعادة حزمه، وتغلب نصوصه نصوص المود.
- اكتب العربية عادية؛ المود يصل الحروف ويعكس الاتجاه بنفسه.
- أبقِ الرموز مثل `%s` و`%d` كما هي.

## الحدود الحالية

- القائمة الرئيسية تبقى إنجليزية: اللعبة لا تحمّل المودات إلا عند فتح الحفظ.
- التشكيل (الفتحة والتنوين...) يُحذف عند العرض، لأن المحرّك لا يضعه فوق الحرف.
- بعض النصوص المركّبة من أجزاء قد تبقى إنجليزية حتى تُترجم مفاتيحها.

## الملفات

- المصدر: [FS22_ArabicLanguage](FS22_ArabicLanguage)، والحزمة: `dist\FS22_ArabicLanguage.zip`
  (منسوخة إلى مجلد المودات).
- الاختبار خارج اللعبة: `python arabic-font-tool\test_mod.py out.png`
