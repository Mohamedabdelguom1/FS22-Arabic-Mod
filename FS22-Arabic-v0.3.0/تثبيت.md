# تعريب Farming Simulator 22 — الإصدار 0.3.0

ترجمة 4059 نصاً من 4206 (97%)، بحروف موصولة ومن اليمين إلى اليسار.

## التثبيت (خطوتان)

1. **الخط (ضروري، فالمود لا يعمل بدونه):** بعد تثبيت بايثون و`pip install numpy pillow` شغّل:
   `python tools\add_arabic_glyphs.py --game "<مجلد اللعبة>"`
   تضيف الأداة الحروف العربية إلى `shared\font\defaultFont` وتحفظ الأصل تلقائياً.
2. **المود:** انسخ `FS22_ArabicLanguage.zip` إلى:
   `Documents\My Games\FarmingSimulator2022\mods\`
   ثم فعّله عند اختيار الحفظ.

## الإلغاء

- احذف `FS22_ArabicLanguage.zip` من مجلد المودات.
- أعد الخط الأصلي: `tools\add_arabic_glyphs.py --game "<مجلد اللعبة>" --restore`
  أو انسخ ملفيك الأصليين مكانه.

## محتويات المجلد

## تعديل ترجمة

يحتاج البناء إلى نصوص اللعبة الإنجليزية `l10n_source.xml`، ولا تُنشر هنا لأنها ملك الشركة.
يصدّرها المود نفسه عند فتح أي حفظ إلى `Documents\My Games\FarmingSimulator2022\modSettings\FS22_ArabicLanguage\`؛ انسخها إلى مجلد `translation`.

عدّل السطر في ملف `translation\ar_*.txt` ثم ابنِ ملف الترجمة:

```bash
python tools/build_translations.py translation/l10n_source.xml translation/ar_*.txt source/FS22_ArabicLanguage/translations/l10n_ar.xml
```

ثم اضغط مجلد `source\FS22_ArabicLanguage` في ملف zip وضعه في مجلد المودات.
أو ضع ملف `l10n_ar.xml` في `modSettings\FS22_ArabicLanguage\` فيقرؤه المود دون إعادة حزمه.
