# أداة إضافة الحروف العربية إلى خط اللعبة

تضيف 223 حرفاً عربياً (بأشكالها الموصولة، وبنسختين: عادي وعريض) إلى خط اللعبة الوحيد
`shared/font/defaultFont`، دون المساس بأي حرف أصلي.

## الاستعمال

التركيب (يحفظ نسخة الأصل مرة واحدة باسم `.original` ولا يكتب فوقها أبداً):

```bash
python add_arabic_glyphs.py --game "D:\Farming-Simulator-22-AnkerGames\Farming Simulator 22"
```

الاسترجاع إلى الخط الأصلي:

```bash
python add_arabic_glyphs.py --game "D:\Farming-Simulator-22-AnkerGames\Farming Simulator 22" --restore
```

تجربة دون لمس اللعبة: أضف `--out مجلد` فتُكتب النتيجة هناك فقط.
تغيير الخط: `--font` و`--font-bold` (الافتراضي Segoe UI من ويندوز).

المعاينة (ترسم النص كما ترسمه اللعبة):

```bash
python preview.py "..\shared\font" out.png "نص للتجربة"
```

## ملاحظات

- يمكن تشغيل الأداة أكثر من مرة؛ فهي تبني دائماً من النسخة الأصلية.
- خط Segoe UI ملك مايكروسوفت: يصلح للاستعمال الشخصي. وللنشر العام استعمل خطاً حراً مثل Noto Sans Arabic.
- الحروف وحدها لا تكفي: وصل الحروف وعكس اتجاه الكتابة داخل اللعبة هو عمل المود (الخطوة التالية).
  وملف `preview.py` فيه القواعد نفسها التي سيتبعها المود.
